# Lanzarote 3D - External Embed Package

This folder contains a standalone, deployable package for embedding the Lanzarote 3D Famara animation as a website background.

## What's Included

- `index.html` - Demo page showing the animation as a background with overlaid content
- `dist/` - Self-contained build artifacts (generated by build script)
  - `animation.bundle.js` - The Famara 3D animation bundle
  - `assets/` - 3D models and textures
  - Additional bundle files for code splitting

## Building

From the project root, run:

```bash
npm run build-external-embed
```

This will:
1. Build all applications using webpack
2. Replace `external-embed/dist/` with the fresh bundles and assets
3. Start a local server at `http://localhost:8081`

## Running Locally

To run without rebuilding:

```bash
npm run run-external-embed
```

## Deployment

The `external-embed` folder is completely self-contained and can be deployed independently:

### Option 1: Static Hosting (Vercel, Netlify, GitHub Pages)

Simply deploy the entire `external-embed` folder as a static site.

**Vercel:**
```bash
cd external-embed
vercel
```

**Netlify:**
```bash
cd external-embed
netlify deploy --dir=.
```

**GitHub Pages:**
```bash
# Push the external-embed folder to a gh-pages branch
git subtree push --prefix external-embed origin gh-pages
```

### Option 2: AWS S3

```bash
aws s3 sync external-embed/ s3://your-bucket-name/ --profile your-profile
```

### Option 3: Any Web Server

Upload the contents of `external-embed` to your web server's public directory.

## Integration

To integrate the animation into your own website:

1. Copy the `dist/` folder to your website
2. Add the required HTML structure to your page:

```html
<!-- Required divs for the animation. data-story picks the scene: every
     bundle shares one entry, which otherwise reads the scene from the URL
     and falls back to home. -->
<div id="root" data-story="famara-animation"></div>
<div id="ui-controls"></div>
<div id="legend-points"></div>
<div id="stats"></div>
<div id="daytime"></div>

<!-- Your content goes here -->
<div class="your-content">
  <!-- ... -->
</div>

<!-- Load the animation bundle -->
<script src="dist/animation.bundle.js"></script>
```

3. Add CSS to position the animation as a background:

```css
/* Make animation container fixed background */
#root {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    z-index: -1;
}

/* Hide UI controls */
#ui-controls,
#legend-points,
#stats,
#daytime {
    display: none !important;
}

/* Hide app selection UI */
#root > div > div:first-child {
    display: none !important;
}

/* Make your content appear over the animation */
.your-content {
    position: relative;
    z-index: 1;
}
```

## Technical Details

- **LOD Level**: ULTRA_LOW (optimized for background use)
- **Browser Support**: any browser with WebGL 2

## Customization

The animation settings can be modified in the source files:
- Camera path: `src/applications/famara-animation/cameraAnimation.ts`
- Animation duration: `src/applications/famara-animation/config.ts`
- LOD settings: `src/applications/famara-animation/index.tsx`

After modifications, rebuild with `npm run build-external-embed`.
